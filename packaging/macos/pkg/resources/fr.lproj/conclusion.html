Stuga démarre. Votre navigateur ouvre sa page de configuration dès que Stuga fonctionne ; sinon, choisissez Configurer Stuga… dans le symbole Stuga de la barre des menus.

Si votre navigateur demande à trouver des appareils sur les réseaux locaux, choisissez Autoriser : c’est ainsi qu’il accède à Stuga.

Une fois Stuga configuré, les autres appareils de votre réseau ouvrent l’adresse indiquée dans le menu. Afficher l’adresse en code QR… l’affiche sur un téléphone.
